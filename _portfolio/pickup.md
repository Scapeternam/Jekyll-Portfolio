Marketplace de services urbains couvrant **19 types de missions** : coursier, conciergerie, photo et B2B. Modèle **driver-first** avec répartition transparente **85/15**.

**Points techniques :**
- **React 18** avec Tailwind CSS et **shadcn/ui**
- 3 portails distincts : Particulier, Professionnel, Livreur
- POD sécurisé (QR Code + PIN + photo + signature)
- Paiement **Stripe Connect** avec split automatique
- Design system complet, **mobile-first**
- Base44 comme Backend-as-a-Service
